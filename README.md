## Overview

Git Mates is a developer-focused tool that analyzes your GitHub followers to identify non-reciprocal relationships, providing valuable insights into your social graph. Built with Next.js and Tailwind CSS, it offers a sleek, responsive interface for exploring followers, imposters, and mutual connections.

**Why Git Mates?**

This project helps developers better understand their GitHub social network by visualizing follower dynamics and engagement. The core features include:

- 🧩 **🔍 Social Graph Analysis:** Identifies imposters and mutual followers to clarify your social connections.
- 🚀 **API Integration:** Seamlessly interacts with GitHub's API via Octokit for real-time data retrieval.
- 🔐 **Secure Authentication:** Implements OAuth flow with token refresh and session management for safe access.
- 🎨 **Custom Styling:** Uses Tailwind CSS for a cohesive, customizable visual experience.
- ⚙️ **Robust Architecture:** Modular design with middleware, components, and utilities for maintainability.

## Getting Started

### Prerequisites

This project requires the following dependencies:

- **Programming Language:** TypeScript
- **Package Manager:** Npm

### Installation

Build git-mates from the source and install dependencies:

1.  **Clone the repository:**

        ❯ git clone https://github.com/sahilxkhadka/git-mates

2.  **Navigate to the project directory:**

        ❯ cd git-mates

3.  **Install the dependencies:**

**Using [npm](https://www.npmjs.com/):**

    ❯ npm install

### Usage

Run the project with:

**Using [npm](https://www.npmjs.com/):**

    npm start

### Testing

Git-mates uses the {**test_framework**} test framework. Run the test suite with:

**Using [npm](https://www.npmjs.com/):**

    npm test
